Follow these steps once to send every saved record directly to a Google Sheet:

  1. Open Google Sheets and create a new spreadsheet.
  2. Go to Extensions → Apps Script.
  3. Delete the default code, then paste the script below and click Save.
  4. Click Deploy → New deployment, set type to Web app, set "Who has access" to Anyone, and click Deploy.
  5. Copy the Web app URL and paste it in the field below, then click Save URL.
