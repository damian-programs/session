Import from Excel

Upload Session_Import.xlsx. The first sheet is read. AGENCY NO becomes the site ID. Organization Name becomes the site name. The two attendees, the administrator, and the on-site supervisor become trained personnel. Email is for reminders; Email2 reaches the supervisor. Address, dates, hot or cold, hours, service time, and days serving come along too. A Google Attendance Link column (or Attendance Link / Google Attendance / Attendance Tab) is read into each site's attendance link; a link already entered by hand is kept when the file has no such column. PINs and notes you already set are kept. Delivery-quantity columns in the file are ignored.

Export reports

Every report below reads the same live records. Pick one and export it. Meal Count Sheets for a single record come from the buttons on each row in Site Lookup, after you press Load there.

Site Summary Sheet Report

One site, a range of months. A single Daily Meal Details sheet listing every day that site serves: service date, weekday, status, received, available, 1st and 2nd meals, with blanks where nothing came in, a total row, and a live DAYS SERVED formula.

Weekly Waste & Leftover Report

One week, Mon–Sat, every site. A Summary with totals and waste and leftover as a share of available, then Waste by Day, Leftover by Day, and Review Flags for the week. Pick any day in the week; it snaps to Monday. Use it to spot over-ordering.

Site Audit Report

One site, one date range, in the CACFP audit layout: daily details, monthly averages, monthly totals, site information. For when a monitor or the state asks for a site's full history.

Monthly Audit Report

A month across all sites, or one: the Sponsor Monthly Meal Count Summary by site. Review Flags now live on the Weekly Waste & Leftover Report, and the raw daily rows come from All Records (CSV).

Initial Estimated Reimbursement

One sheet in the compliance department's format. Per site: Received, Available, Attendance, 1st and 2nd meals. Real 2nds are capped at 2% of 1sts. Then a total and an estimate at the supper rate set on the Reimbursement tracker. This is the first pass for the monthly claim.

All Records (CSV)

Every record, every site, one row each, all fields. For spreadsheets and pivot tables.

Admin PIN

The PIN used to sign in as Monitor Organization. It lives in Firestore (site_info/MONITOR) now, not in the app's source file, so it can be changed here without redeploying. Anyone who reaches this tab is already signed in as Monitor — treat this the same as any shared password, and note that Firestore's rules here allow open read/write, so this isn't hardened against someone reading the database directly.

Email (Postmark)

Reminders go out through Postmark from kids@clevelandfoodbank.org, to the administrator (and supervisor, when on file) of each site you tick in Site Tracker. A small Cloudflare Worker holds the Postmark server token, so it never sits in this page. The Relay URL below is that Worker's own address — it looks like https://session-mail.your-subdomain.workers.dev. It is not a Postmark address: a browser cannot talk to an SMTP host such as smtp-broadcasts.postmarkapp.com. The relay URL, sender, and stream save to Firebase (app_config/email) for every monitor; the access key stays in this browser only, so each monitor enters it once on each computer they use.

Reminder email text

This is the message sites get when you tick them in Site Tracker. Edit it here; the change saves to Firebase and applies to every monitor. Words in curly braces are filled in per site when the email is sent.
